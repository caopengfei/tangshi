# 唐诗三百首 · Android TV 学习应用 设计文档

> 2026-10-06 定稿。基于 brainstorming 阶段的逐屏 mockup 评审（记录于 `.superpowers/brainstorm/`）。
> 姊妹项目 `threecharactorscripture`（三字经）的语音生成实践直接沿用，见第 8 节。

## 1. 项目概述

- **定位**：儿童启蒙为主的唐诗学习应用，家庭客厅场景，遥控器操作，完全离线。
- **用户**：小学生及以下儿童，家长陪读/家长设置。单学习档案（不做多孩子档案）。
- **平台**：Android TV，Kotlin + Jetpack Compose for TV。
- **内容**：通行本《唐诗三百首》（蘅塘退士编，约 310 首，具体以数据文件为准，UI 计数动态取实际值）。
- **用语约定**：全 app 只出现"唐诗/诗"，不出现"诗词"（诗题原名如《凉州词》除外）。

## 2. V1 范围

**做**：诵读跟读（逐字拼音 + 逐句音频高亮）、学习进度跟踪（状态/进度/连续天数）、家长讲解辅助（创作背景故事）、背诗小游戏（填空补诗 + 听音辨诗）、搜索（诗人 + 关键字）、全部唐诗浏览、家长设置。

**明确不做（V1）**：多档案、朝代筛选、家长门、诗句排序/诗句配对玩法、在线内容、语音搜索、多音色切换、asset pack 拆分。

## 3. 技术栈与工程结构

| 项 | 选择 |
|---|---|
| 语言/UI | Kotlin 2.x + Jetpack Compose for TV（androidx.tv material3） |
| 播放 | Media3 ExoPlayer（逐句播放、变速不变调） |
| 持久化 | Room（仅学习进度；诗词内容为静态 JSON 不入库） |
| minSdk / target | 24 / 最新稳定 |
| 包名 | com.rakor.tangshi |

```
tangshi/
├─ app/src/main/assets/content/poems.json        # 全部诗数据（含拼音、创作背景）
├─ app/src/main/assets/audio/{poemId}/            # 逐句音频 + manifest.json
├─ tools/                                         # 语音生成脚本、对照稿、同音字替换表
└─ docs/                                          # 本文档
```

工具链：Android Studio `D:\develop\soft\Android Studio`，SDK `D:\develop\androidsdk`。

## 4. 视觉规范（风格 D · 童趣暖阳）

- **底色**：奶油渐变 `#fff6e8 → #fdefdd → #fde8d8`（160°）。
- **卡片**：白色圆角（大卡 20dp、小卡 14~18dp）+ 暖棕柔和投影（`rgba(210,140,90,.14~.22)`），焦点卡片珊瑚橙描边（2~3dp）+ 光晕阴影。
- **主色**：珊瑚橙 `#ff7a50`（按钮、进度、焦点、强调），渐变按钮 `#ff9a76 → #ff7a50`。
- **文字**：标题暖棕 `#6b4f3a` / `#7a5c48`，正文 `#7a6450`，次要 `#c0987e` / `#c0a090`，浅底胶囊 `#fff2ea`、徽章底 `#ffe9de`。
- **点缀色**：琥珀 `#ffb347`（结算星星）。
- **字体**：诗体内容用楷体系（KaiTi 回退），界面常规用系统无衬线；诗名大字号、宽字距（letter-spacing ≈ 3~4）。
- **图标**：全部使用单色矢量图标（Material Symbols）染主题色（珊瑚橙/暖棕），**禁止彩色 emoji 图标**；"已会背"徽章统一用 thumb_up（实心）。
- **通用布局**：16:9 全屏，顶部标题行 + 主内容区 + 底部按键提示行；焦点元素放大 1.05~1.1 + 描边动效。

## 5. 页面规格（8 屏）

### 5.1 首页
- 顶栏：左"唐诗三百首"，右鼓励语（"小朋友，今天继续加油哦 🌞"）。
- 左主卡（约 60% 宽，珊瑚橙描边）："当前学习 · 第 N 首"标签、诗名大字 + 诗人姓名、全诗文字、诵读进度条、"▶ 继 续 诵 读"渐变按钮 → 详情页。无当前学习诗时显示第一首未学的诗，按钮文案"开 始 诵 读"。
- 右统计列（3 张白卡）：📚 已学唐诗 N / 总数、🔥 连续学习 N 天、👍 已会背诵 N 首。
- 底部入口：🔍 搜索（珊瑚橙描边突出）｜📚 全部唐诗｜🎮 背诗小游戏｜⚙️ 家长设置。
- 底栏提示：◀ ▲▼ 选择　OK 确认。

### 5.2 诗学习详情页
- 顶栏：← 返回｜诗名 + 诗人（"唐 · 李白"格式）｜第 N / 总数 首。
- 左卡（约 58%）：全诗逐字拼音（ruby 式，字大拼音小）、**当前朗读句整句高亮**（浅橙底圆角 + "◀ 正在读"标记）；下方按钮排：▶ 朗读（渐变实心）｜🔁 逐句跟读｜👍 我会背了（描边）。
- 右卡："🌙 诗人为什么写这首诗？"——创作背景故事（孩子能听懂的口语化叙述，一首一段）。
- 按键：◀ ▶ 逐句移动　OK 播放/暂停　B 返回。
- "我会背了"点击后弹确认，确认后该诗标记已会背（第 9 节）。

### 5.3 搜索页
- 顶栏：珊瑚橙线条放大镜矢量图标 + "搜索唐诗"｜← 返回。
- 筛选行：诗人：全部 ▾｜✏️ 诗名/诗句关键字（无朝代筛选）。
- 诗人筛选：中央网格浮层，按拼音排序，每项"姓名 + 收录诗数"（如 李白 29），含"全部诗人"复位项；◀ ▲▼▶ 移动，OK 选中并实时过滤。
- 关键字：右侧屏幕键盘（字母 A~Z + 删除 + 搜索），边输边出结果；关键字**同时匹配**标题/诗句汉字文本与其全拼序列（如输入 `jingyesi` 命中《静夜思》，拼音取自 7.1 的 `chars.py`）；结果列表每行"诗名 · 诗人｜首句预览（命中字高亮）"。
- 结果行：▲▼ 浏览　OK 进入该诗详情页。

### 5.4 全部唐诗
- 顶栏：标题 + "共 N 首 · 已学 M 首"｜← 返回。
- 筛选行：全部（选中态渐变实心）｜未学习｜学习中｜已会背 👍。
- 网格 4×2 每页 8 张卡：**一卡一诗**——诗名大字居中、诗人姓名居中（不带朝代前缀）、状态徽章贴卡片底部居中（未学习=灰底 / 学习中=浅橙底+进度% / 已会背=👍+橙底）。
- 底部：页码（OK 翻页，◀▶ 也可跨页移动）；按键 ◀ ▲▼▶ 浏览　OK 学习　B 返回。

### 5.5 背诗小游戏入口
- 两张玩法大卡：**填空补诗**（thumb_up 矢量图标，"诗里缺了个字，选出来！"）、**听音辨诗**（speaker 矢量图标，"听朗读，猜猜是哪首诗？"），副标题均注明"10 题一轮 · 支持已学唐诗"。
- 右侧题目范围竖排胶囊：今日所学（默认）/ 已学全部 / 全部 300 首。
- 按键：◀ ▲▼ 选择玩法和范围　OK 开始。

### 5.6 游戏题面（A 填空补诗 / B 听音辨诗）
- A：诗全文展示、挖空字显示橙色"？"方块；底部 4 个候选字（1 正确 + 3 干扰，干扰取同诗其他字或同难度常用字）；◀ ▶ 移动 OK 选择；答对变绿反馈、答错震动提示后可继续。
- B：大播放圆钮（可重听，限 3 次）+ "听一听，这是哪首诗？"；底部 3~4 个诗名选项卡。
- 顶部：题号进度 + 连对计数。

### 5.7 结算页
- 三星展示（琥珀色，按得分点亮）、"答对 X / 10 题！"、鼓励语（10 题："诗仙驾到！"；≥7："太棒了！"+ 连续天数；<5："再试一次会更棒"）。
- 按钮：▶ 再来一轮｜返回首页。

### 5.8 家长设置（无家长门，直接进入）
- 双列卡片：朗读语速（慢 0.9× / 正常 1.0× / 快 1.15×，默认正常——播放倍率，作用在已生成的 0.85 基准语速之上，ExoPlayer 变速不变调）、跟读模式（逐句暂停✓默认 / 连续播放）、按键提示音（开✓/关）、清除学习进度（→ 二次确认对话框）。
- 底栏：关于（版本号 · 唐诗数据来源说明）。
- 按键：◀ ▲▼▶ 选择　OK 修改　B 返回。

## 6. 导航与按键

单 Activity + Compose Navigation。路由：`home` / `poem/{id}` / `search` / `library` / `gameSetup` / `game/{mode}` / `gameResult` / `settings`。
系统键：B/返回键逐级回退；OK 确认；菜单键映射至家长设置入口。焦点必须始终可见（TV 可达性硬要求），首次进入各屏给默认焦点。

## 7. 数据设计

### 7.1 诗词数据（assets/content/poems.json）

```json
[{
  "id": "jing-ye-si", "order": 13,
  "title": "静夜思", "poet": "李白", "dynasty": "唐",
  "lines": [
    {"text": "床前明月光，",
     "chars": [{"c":"床","py":"chuáng"},{"c":"前","py":"qián"},{"c":"明","py":"míng"},{"c":"月","py":"yuè"},{"c":"光","py":"guāng"}]},
    …
  ],
  "background": "李白年轻时离开家乡……"
}]
```

- `chars.py` 是**唯一发音权威**：详情页拼音标注与语音包校对共用（第 8 节）。
- `background` 为家长讲解辅助文案，一诗一段、口语化、80~150 字。

### 7.2 学习进度（Room）

```
poem_progress: poemId(PK) · status(NOT_STARTED/LEARNING/MASTERED) · progress(0-100) · lastPlayedAt · masteredAt
study_log: date(PK) · poemsTouched
```

**规则（无歧义定义）**：
- 进入详情页且播放过任一句 → status=LEARNING；
- `progress = 播放过的句数 / 总句数 × 100`（同一句重复播放不重复计）；
- 点"👍 我会背了"并确认 → status=MASTERED、progress=100、masteredAt 记录；
- MASTERED 后可继续听读但状态不回退（重置需家长设置清除进度）；
- 连续天数：当日 study_log 有记录则 streak 延续，断一天清零重计；
- "今日所学" = 当日 lastPlayedAt 命中的诗集合。

### 7.3 搜索实现

300 首规模无需全文索引：启动载入内存，诗人过滤 + 标题/诗句 `contains` 匹配即可。

## 8. 语音生成流水线（沿用三字经项目实践）

**通道**：airvoz.com 网页版 TTS 接口（详见 `threecharactorscripture/docs/voice-generation.md`）：

```
POST https://airvoz.com/api/tts
Content-Type: application/json
{"input":"<TTS输入文本>","voice":"zh-CN-XiaoshuangNeural","language":"zh-CN","speed":0.85,"pitch":1,"volume":1}
```

- 音色 **zh-CN-XiaoshuangNeural（儿童声「晓双」）**——V1 默认且唯一音色；`speed=0.85` 为放慢跟读节奏，**不可改**；pitch/volume=1。
- 该接口**只能从站点页面上下文调用**（curl 直连返回空 body），批量生成用 ZCode browser-use 自动化在打开的页面里循环 fetch；单次 ≤3000 字符（诗句远小于），并发 ≤3、失败指数退避（免费服务，勿加压）。
- 逐句请求，产出：

```
app/src/main/assets/audio/{poemId}/line1.mp3 … lineN.mp3
app/src/main/assets/audio/{poemId}/manifest.json   ← 每句时长（ffprobe 测得），句间停顿(逗号300ms/句号600ms)由播放器按此插入
```

- **无全诗连读文件**（冗余）：连读 = ExoPlayer 播放列表顺序播放逐句文件 + manifest 停顿；跟读 = 单句循环。
- **转码**：API 产出 MP3 → ffmpeg 转单声道 Opus 24kbps（纯人声无损听感），全量预计 8~10 MB，随 APK 打包。
- **多音字对策：同音字替换**（与三字经同法）：只改喂给 TTS 的文本，app 显示文本永不变；替换必须 **1:1 同字数**（如 子→紫、教→叫）以保句子节奏；替换表存档于 `tools/voice_script.txt`（A 节逐句对照稿 / B 节替换表）。生成前用 7.1 的 `chars.py` 拼音数据全量扫描多音字生成待校对清单，人工逐个确认替换方案；**校对表覆盖不到的多音字生成脚本直接报错**，不允许裸奔合成。
- **校验与抽查**：每条先落 `build/voice-staging/`，MP3 魔数（ID3 或 0xFFEx）+ >1KB 校验后落定；全部完成后整体覆盖 assets（不边生成边覆盖）；跑单测（对齐三字经 `AudioAssetsTest` 模式：逐句齐全、>1KB、魔数、与 manifest 句数一致）；模拟器试听抽查（重点：替换表涉及句 + 生僻字）。
- **真人语音包替换**：同目录同名覆盖音频文件 + 更新 manifest 时长即可，UI/逻辑零改动；显示拼音以 7.1 数据为准。
- **Fallback**：airvoz 失效时降级 edge-tts（晓双为 Azure 专有、edge-tts 无此音色，应急用 zh-CN-XiaoxiaoNeural，多音字错误率相同需同表替换）。

## 9. 游戏规则

- 题池：按入口选择的范围（今日所学 / 已学全部 / 全部）取诗；范围不足 5 首时提示先去学诗。
- 填空补诗：每题随机一诗一句挖 1 字（避开标点前后首字）；候选 = 正确字 + 3 干扰（优先取自同诗其他字，不足补常用字）。
- 听音辨诗：播报范围池内某诗的随机一句音频，从 3~4 个诗名选项中选；音频直接复用逐句语音包。
- 每轮 10 题；星级：3 星 ≥9 题、2 星 ≥7 题、1 星 ≥5 题、其余 0 星；结算文案见 5.7。
- 游戏结果**不直接**改变学习状态（会背仍以详情页 👍 为准），但计入当日 study_log。

## 10. 错误处理与边界

- 音频文件缺失/损坏：播放静默失败并在详情页顶部显示一次性提示条，功能不崩溃（单测保证资产齐全）。
- 数据加载：poems.json 解析失败（开发期问题）直接抛出并记 log，不静默。
- 焦点丢失场景（浮层关闭、列表翻页）必须回落到合理默认焦点。
- 清除进度需对话框二次确认；确认后 Room 全表清空并回首页刷新。

## 11. 测试策略

- 单测：poems.json 解析与拼音对齐（chars 数与 text 非标点字符数一致）、进度规则、游戏出题（范围过滤/干扰项生成/不重复抽题）、manifest 完整性。
- 资产测试：对齐三字经 `AudioAssetsTest` 模式——逐句文件齐全、>1KB、魔数正确、manifest 句数一致。
- UI 冒烟：模拟器（TV image）走通首页→详情→播放→列表→搜索→游戏一轮→结算→设置。
